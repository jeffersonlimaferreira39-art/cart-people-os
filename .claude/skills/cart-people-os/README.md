# Skill cart-people-os

Faz o Claude trabalhar no C'Art People OS como engenheiro sênior, arquiteto, especialista em
segurança e designer frontend, seguindo a especificação do produto.

- `SKILL.md` — padrão de trabalho, regras inegociáveis e definição de pronto.
- `references/PRODUCT_SPEC.md` — requisitos, papéis, modelo de dados, RLS, LGPD, design system e
  critérios de aceite.

**Uso no Claude Code:** já é carregada automaticamente por estar em `.claude/skills/` do repositório.
**Uso no Claude (app):** envie o arquivo `cart-people-os-skill.zip` na área de skills das configurações.
